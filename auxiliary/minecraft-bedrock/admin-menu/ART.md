# Icono propio

`resource_pack/textures/raynor/enchanting_table.png` fue generado con la herramienta
integrada image_gen, no con CLI. Se inspecciono visualmente y se conservo su transparencia.
El resto son referencias a iconos vanilla, sin copiar sus bitmaps.

Prompt usado:

> Create ONE game inventory UI icon, square canvas, transparent background. Subject: a Minecraft-style enchanting table, isometric three-quarter view: squat black obsidian cubic pedestal with cyan diamond corner accents, red tabletop, small open cream-colored floating book above it. Crisp low-resolution pixel art, chunky pixel edges, limited palette, no smooth gradients, no shadow outside the object, no text, no frame. Centered entire table and book with 10% transparent padding, readable at 32x32 pixels. Save as PNG asset for the current project.
