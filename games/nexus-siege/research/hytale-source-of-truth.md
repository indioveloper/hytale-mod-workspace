# Hytale Source Of Truth

Last updated: 2026-07-11

## Rule

The Hytale source code on GitHub is the source of truth for technical questions
about vanilla behavior, asset schemas, NPC systems, trigger volumes, and server
APIs.

## Local Reference

There is also a local checkout at:

`hytale-shared-source/`

Use the local checkout for fast inspection first. When a detail may have changed
or exact current behavior matters, verify against the GitHub source.
