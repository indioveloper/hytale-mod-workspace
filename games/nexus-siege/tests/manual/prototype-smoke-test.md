# Prototype Smoke Test

Last updated: 2026-07-11

## Goal

Verify that the first playable prototype can run end to end.

## Checklist

- Server starts with the prototype enabled.
- Match can be started manually.
- Players are assigned to the correct teams.
- Players spawn in the correct bases.
- Both nexuses appear correctly.
- Nexus health is visible to players.
- Damaging a nexus updates its health display.
- Destroying a nexus ends the match.
- The winning team is announced clearly.
- The arena resets cleanly for another run.
