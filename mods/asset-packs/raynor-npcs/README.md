# Raynor NPCs

Reusable NPC toolkit for Raynor/OrbGenesis projects.

Version `1.1.1`, compiled and validated against Hytale Update 6 stable `0.6.2`.

This pack is the canonical home for:

- Raynor NPC roles and spawn markers.
- Shared NPC roles that are useful outside a single project.
- Trigger Volume effects for NPC spawning, equipment, and item cleanup.

Included roles and markers:

- `Raynor_Klops_Miner_Patrol`
- `Raynor_Static_Guard`
- `Raynor_Static_Human_Emoter`
- `Raynor_Worker_Route`
- `Nexus_Avatar_Sword_Runner`

Included Trigger Volume effects:

- `SpawnNpcRandomModel`
- `EquipNpcItem`
- `RemoveOneItemInVolume`

The old `Triggers_NPCs` plugin and `Nexus Siege NPCs` asset pack have been
absorbed here so projects can depend on `Raynor:Raynor NPCs` instead of a
Nexus-specific mod.
