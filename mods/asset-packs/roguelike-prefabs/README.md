# Roguelike Prefabs

Asset pack instalado como `tests:tests` y usado por la partida
`test roguelike`.

Incluye:

- listas de prefabs de salas roguelike;
- los mapas `mapa 1` y `mapa 2`;
- salas base, profundas y de lava;
- puertas, barrotes y piezas auxiliares.

Para instalarlo, copia esta carpeta a:

```text
%APPDATA%\Hytale\data\pre-release\Mods\tests.tests
```

El identificador `tests:tests` se conserva porque la configuracion de la
partida y Map Selector ya hacen referencia a el.
