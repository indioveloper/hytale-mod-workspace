# More Triggers

Mod Java para Hytale que amplia Trigger Volumes con efectos extra.

Estado actual:

- `RemoveEventTitle`
- `RandomTagSelection`
- `PasteRandomPrefab`

Origen:

- el codigo fuente canonico se ha recuperado desde las carpetas legacy
  `more-triggers-src` y `more-triggers-stage`

Notas:

- el modulo estaba en el repo solo con `.build`; ahora vuelve a tener `src`
- antes de usarlo en una version nueva del juego conviene recompilarlo contra el
  `HytaleServer.jar` correcto y validar localizacion y assets
