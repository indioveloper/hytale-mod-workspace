# Trigger Execute Command

Mod para Trigger Volumes que registra el efecto `ExecuteCommand`.

El efecto ejecuta un comando desde la consola del servidor o desde el jugador
que activa el volumen. Soporta marcadores simples:

- `{player}`
- `{uuid}`
- `{x}`
- `{y}`
- `{z}`

Estado: actualizado a rango de pre-release 0.6.x. Debe compilarse y probarse en
0.6.8 antes de instalarlo en un save con triggers existentes.
