# Retired More Triggers effects

Codigo deprecated retirado del JAR activo de More Triggers.

- `RemoveEventTitle`: conservado como referencia historica desde More Triggers
  1.6.0. No se registra ni se distribuye.
- `NoMoveEffect`: registro erroneo anterior a 1.9.0. `Always Active` solo
  muestra reglas; el reemplazo activo conserva el ID `NoMove` mediante
  `NoMoveRule` y `NoMoveRuleSystem`.

`RandomTagSelection` no se conserva: se elimino por decision de diseno porque
su inclusion original fue un error.
