Cómo funciona

1. Mob y Oleadas

Elige el NPC y personaliza su nombre, vida, escala y actitud. La tarjeta compara su tamaño con un jugador de 1,85 m.

2. Spawner

Define cuándo se activa, cuántos mobs aparecen, la cadencia, la luz permitida y el rango de aparición. El mapa muestra un ejemplo dinámico.

3. Armas y armadura

Asigna un objeto o bloque a la mano y piezas de armadura. Algunos modelos aplican sus propiedades aunque no puedan representarlas visualmente.

4. Loot

Conserva, elimina, amplía o sustituye el loot vanilla. Cada objeto permite indicar cantidad mínima, máxima y probabilidad.

Exportar e importar

La web genera automáticamente un string CMS1. Pulsa Copiar y pégalo en Importar string dentro del editor del spawner en Hytale. Importar spawner sirve para cargar aquí un CMS1 anterior, revisarlo y seguir editándolo; no modifica la partida.
