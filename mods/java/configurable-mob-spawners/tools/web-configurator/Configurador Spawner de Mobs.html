Cómo funciona

1. Crea tus Mobs

Elige un NPC y usa «Añadir Mob» para crear más perfiles. Sus pesos determinan con qué frecuencia aparece cada uno.

2. Objetos equipados

Asigna un objeto o bloque a la mano y piezas de armadura. Algunos modelos aplican sus propiedades aunque no puedan representarlas visualmente.

3. Loot y élites

Configura el loot normal y, si habilitas la variante élite, su probabilidad, modificadores, equipo alternativo y loot adicional.

4. Configura el Spawner

Define cuándo se activa, cuántos mobs aparecen, la cadencia, la luz permitida y el rango de aparición. El mapa muestra un ejemplo dinámico.

Exportar e importar

La web genera automáticamente un único string CMS1 con todos los perfiles. Pulsa Copiar y pégalo en el editor del spawner en Hytale.
